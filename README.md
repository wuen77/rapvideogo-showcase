# RapVideoGo — AI Rap Video Generator

Create personalized rap videos from reference photos and text prompts.

[Visit RapVideoGo](https://rapvideogo.com)

## What is RapVideoGo?

RapVideoGo is a web-based AI tool for creating personalized rap videos.
Use it to turn photos and creative ideas into solo performances or duets
for birthday greetings, family moments, and social media content.

This repository contains product information and usage examples.

## Features

- Use up to nine reference images.
- Write lyrics and describe scenes, character actions, and camera movement.
- Specify who performs each line in duet prompts.
- Choose the video aspect ratio, duration, and resolution.
- Start with editable examples.
- Use the interface in English or Chinese.

## How to use

1. Visit RapVideoGo and choose an example or start your own prompt.
2. Upload your reference photos.
3. Enter lyrics and describe the performance.
4. Choose your video settings and generate your video.

Video generation uses paid credits.
